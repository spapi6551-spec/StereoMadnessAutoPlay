# Stereo Madness AutoPlay

Experimental Geode mod for Geometry Dash 2.2081.

## Build

Install the Geode SDK/CLI, set `GEODE_SDK`, then run:

```bash
geode build -p android64
```

The generated `.geode` can be installed on an Android Geode installation.

## Important

The included input table is an experimental example. It is **not** a verified
100% TAS of Stereo Madness. For a true 0-100% bot, replace `EVENTS` with
timestamps extracted from a verified replay.
